# Apply Harvard Referencing

## Establish the controlling standard

Apply this authority order and record any conflict:

1. Follow explicit current module, supervisor, or institutional instructions.
2. Follow the Harvard guide explicitly designated by the user for the task.
3. Read [references/guide-rules.md](references/guide-rules.md) for core UEL/Cite Them Right rules.
4. Read [references/dissertation-source-formats-12th_Codex.md](references/dissertation-source-formats-12th_Codex.md) only for the source types present.
5. Use general Harvard knowledge only for uncovered cases and label each decision as an assumption.

State the exact Harvard variant used. Never imply that one universal Harvard standard exists. Do not mix variants within one document.

Unless a higher authority says otherwise, apply the UEL profile: use the first author plus italicised *et al.* for four or more authors in text, and list all named authors in the reference list.

## Preserve the manuscript

- Change only in-text citations, citation punctuation, source-attribution mechanics, and bibliographic entries unless the user expressly authorises broader editing.
- Preserve arguments, prose, vocabulary, grammar, headings, paragraph order, quotations, figures, findings, numbers, currencies, and document structure.
- Do not convert currencies or alter financial values during a citation-only task.
- Do not invent or infer authors, dates, titles, page numbers, editions, publishers, places, URLs, access dates, volumes, issues, article numbers, or DOIs.
- Do not delete a listed-but-uncited source or insert a new in-text citation automatically. Retain and flag it unless the user expressly authorises deletion or placement; it may indicate a missing citation rather than an unnecessary source.
- Do not change wording inside a quotation. Correct its surrounding citation; flag quotation-text issues such as missing ellipses, brackets, or `[sic]` unless the user authorises quotation editing.
- Preserve the existing `References` or `Bibliography` heading unless the controlling standard requires a change.
- Flag a statement that may need evidence as a potential gap; do not claim it is unsupported without checking the underlying sources.

## Audit the complete document

1. **Inventory**
   - Locate every narrative and parenthetical citation, direct quotation, figure-source citation, appendix citation, and final reference entry.
   - Record ambiguous citation-like text instead of silently ignoring it.
2. **Cross-match**
   - Link each citation to exactly one reference entry.
   - Identify cited-but-unlisted sources, listed-but-uncited sources, duplicates, inconsistent corporate names, and author-year collisions.
3. **Classify**
   - Identify the underlying publication type. Treat PDF as a file format, not a source type.
   - Preserve and flag entries whose source type cannot be determined reliably.
4. **Check citations**
   - Check author presentation, year, locator, punctuation, multiple-source ordering, `a`/`b` suffixes, corporate authors, missing author/date, and secondary referencing.
   - Require a locator for a direct quotation when available and for an idea tied to a specific page or section. Do not require a page for every general paraphrase or whole-work summary.
5. **Correct references**
   - Apply the verified template for each supported source type.
   - Alphabetise the final list by author, responsible organisation, or title when no author exists.
   - Preserve the distinction between a reference list and a broader bibliography.
6. **Validate**
   - Re-scan the corrected document and repeat the cross-match.
   - Confirm that no non-citation content changed.
   - Put every missing, unsupported, or uncertain element in the audit rather than inventing content.

## Handle Word dissertations

For `.docx` input, also use the available Word-document skill and its structure-preserving edit and render workflow.

- Preserve the original file unchanged.
- Create one clean corrected copy named `<original-stem>_Codex.docx`; do not use tracked changes unless requested.
- Create a separate audit named `<original-stem>_Harvard_Audit_Codex.md` unless the user requests another format.
- Make the smallest possible run-level or OOXML changes needed to preserve styles, fields, hyperlinks, tables, figures, headers, footers, and pagination.
- Render the corrected DOCX, inspect every page, and repair any layout regression before delivery.
- Compare original and corrected text outside authorised citation/reference regions and report whether preservation passed.

## Report deficiencies

Use direct labels such as:

- `Missing metadata: publication year`
- `Missing locator: direct quotation attributed to Ahmed (2022)`
- `Unmatched citation: (Ahmed, 2022)`
- `Uncited reference-list entry: Ahmed (2022)`
- `Duplicate reference: Ahmed (2022)`
- `Unsupported by controlling guide: source type requires confirmation`
- `Assumption: corporate author normalised to the organisation's published name`

Do not browse for missing metadata unless the user asks for retrieval or verification. When browsing is authorised, distinguish verified metadata from inferred or unresolved metadata.

## Return the result

For pasted text, return:

1. corrected text with citation/reference changes only;
2. an itemised audit log; and
3. a compliance summary.

For a Word dissertation, return the clean `_Codex.docx` copy and the separate audit. Include counts of citations checked, entries checked, corrections made, unmatched items, duplicates, missing locators, incomplete metadata, unsupported cases, and assumptions requiring confirmation.

Do not treat citation-format compliance as source verification, plagiarism assessment, CASP appraisal, or proof that a cited source supports a claim.
