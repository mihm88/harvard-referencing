## Source and authority

This digest is verified against the user-supplied Sections A-F of Pears and Shields' *Cite Them Right: the essential referencing guide*, 12th edition (2022), with the supplied Section G extract used for source formats. The bundled four-page UEL guide based on the 9th edition remains legacy institutional evidence.

If this digest conflicts with a current institutional instruction or the Harvard guide designated for a task, follow the higher authority and record the conflict. The 12th edition states that Harvard has institutional variants.

Harvard uses author-date in-text citations and a final alphabetical list. It does not use footnotes or endnotes for referencing.

## In-text citations

Include the author/editor surname or responsible organisation and publication year. Include `p.` for one page or `pp.` for multiple pages when quoting directly or using material from specific pages.

- Narrative: `Jones (2020)` or `Jones (2020, p. 14)`.
- Parenthetical: `(Jones, 2020)` or `(Jones, 2020, pp. 14-16)`.
- Two authors: cite both names.
- Three authors: cite all three names.
- Four or more authors: cite the first listed author followed by italicised *et al.* unless the institution requires all names.
- Corporate author: use the organisation's full name. Introduce a well-known abbreviation at first use and apply it consistently so the citation matches the reference entry.
- No author/editor: use the italicised title; never use `Anon.` or `Anonymous`.
- No date: use `no date` consistently. With no author or date, use the italicised title and `no date`.
- Web content: cite author and date, or title and date. Use a URL in the citation only when neither author nor title can be identified; flag the source's credibility and metadata limitations.

For several sources in one parenthesis, separate entries with semicolons and arrange them chronologically, earliest first. For sources from the same year, order alphabetically by author/editor.

For several works by the same author in different years, list years chronologically. For two or more works by the same author in the same year, add lower-case `a`, `b`, and so on consistently to both citations and reference entries. Under the supplied 12th-edition rule, assign letters in the order the works are first cited in the text.

For the same lead author, place a single-author work before multi-author works. Order multi-author works by the second author and then subsequent authors.

## Secondary referencing

Minimise secondary referencing and locate the original source whenever possible.

- Use `quoted in` when the source read reproduces the primary author's exact words.
- Use `cited in` when the source read summarises the primary work.
- Cite both works in text, for example `Jang (2015, cited in Lewis, 2018, p. 86)`.
- Include only the source actually read in the reference list.
- Do not represent the primary source as having been consulted.

## Quotations, paraphrases, and summaries

- Cite every quotation, paraphrase, and summary derived from another source.
- Give a page number for a direct quotation whenever pagination exists. If not, use a paragraph, chapter, section, location, percentage, timestamp, or other stable locator supplied by the source.
- Give a locator for a paraphrase or idea drawn from a specific page. A general paraphrase or whole-work summary may use author and year only.
- Put a short quotation of up to about two or three lines in quotation marks within the paragraph.
- Set a longer quotation as an indented block without quotation marks. Follow the institution's document-formatting requirements for spacing.
- Mark omissions with an ellipsis without changing the meaning; put clarifying insertions in square brackets; retain an original error and add `[sic]`.
- Identify added emphasis as `(my emphasis)` or equivalent and source emphasis as `(original emphasis)`.
- For a non-English quotation, retain the original and, if useful, add an English translation in square brackets with `(my translation)`. A paraphrased translation uses no quotation marks but still cites the original.

During a citation-only correction, do not rewrite quotation wording. Flag required quotation-text changes for author review.

## Reference lists and bibliographies

- A reference list contains only works cited in the document.
- A bibliography contains cited works plus relevant background works consulted but not cited.
- Arrange either list alphabetically by author surname, responsible organisation, or title when no author exists. Do not split the list by source type unless the controlling institution requires it.
- Use surname followed by initials. Use `(ed.)` for one editor and `(eds)` for several.
- Under the UEL profile, list all named authors in the final reference list even when *et al.* appears in text.
- Use the title and subtitle as published. Italicise the container title, such as the book, journal, report, or website title where the relevant template requires it.
- Include an edition only when it is not the first: `2nd edn.`, `Rev. edn.`, or equivalent shown by the source.
- Include place and publisher for books and printed reports when the template requires them. Add a US state abbreviation where needed to distinguish the place.
- Include `p.` or `pp.` and full page ranges for chapters and serial articles: `pp. 90-99`, not `pp. 90-9`.
- Do not include ISBNs.

## Metadata and online access

- Prefer a DOI when available and present it as `Available at: https://doi.org/...`.
- Do not add an access date to an ordinary permanent DOI. Follow an explicit source-specific exception in the controlling guide, such as an advanced-online article template that requires one.
- For an ordinary changeable URL, use `Available at: URL (Accessed: day Month year)`.
- Use the complete path needed to locate the material. Shorten only when the route remains unambiguous.
- Include an article number when the publication uses one instead of pages.
- Never invent absent metadata. Preserve the available entry and report the missing element.

## International and dissertation material

- Treat PDF as an access format rather than a publication type. Determine whether the document is a journal article, report, thesis, standard, dataset, book, or another source.
- Prefer the author's or organisation's published name. Apply naming particles and family-name conventions according to the source and authoritative usage.
- For Arabic or other non-Roman material, use an official English title when the publisher supplies one. Otherwise apply the institutionally required transliteration and add an English translation in square brackets.
- Cite a sourced figure in its caption and include the full source in the applicable reference list. Flag permission requirements separately.
- Apply citations inside appendices. Where the controlling guide requires it, place the appendix's full references at the end of that appendix as a separate list.
